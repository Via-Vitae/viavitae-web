# `public/` — static assets

Everything here is served verbatim from the web root (`/`). Binary raster assets
are **launch-gated**: they must be exported from the brand kit, never fabricated
in-repo (QODER rule 4 / spec F-fix). Vector and text assets that can be authored
from the real brand tokens ship now.

## Ships now (authored, real)

| Path                | Status  | Notes                                                                                                                          |
| ------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `icon.svg`          | ✅ real | 512×512 brand mark (navy `#0e1b3d`, gold `#c9a227`, ivory `#f7f4ec`). Referenced by `app/manifest.ts`.                         |
| `og/{lt,en,ru}.svg` | ✅ real | 1200×630 OG **masters** generated by `scripts/generate-og.mjs` from localised home title + footer tagline. See PNG gate below. |

## Launch-gated binaries (export from brand kit before go-live)

| Path                                     | Required by                                       | Gate                                                                                                                                                                                                                                                                     |
| ---------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `favicon.ico`                            | browsers requesting `/favicon.ico`                | Export raster favicon; `app/manifest.ts` currently lists only `icon.svg`.                                                                                                                                                                                                |
| `apple-icon.png` (180×180)               | iOS home-screen                                   | Export from brand kit.                                                                                                                                                                                                                                                   |
| `icon-192.png`, `icon-512.png`           | PWA install prompt                                | Add to `manifest().icons` once exported.                                                                                                                                                                                                                                 |
| `og/{lt,en,ru}.png` (1200×630)           | `components/seo/metadata-builder.ts` (`og:image`) | **Rasterise the committed SVG masters to PNG.** Social crawlers (Facebook/X/LinkedIn) do not support SVG `og:image`. No SVG rasteriser is available in the offline authoring environment; add `@resvg/resvg-js` or `sharp` as a devDependency and rasterise in CI/build. |
| `images/{heroes,products,church,team}/*` | hero/product/team imagery (srcset AVIF/WebP)      | Real photography/illustration. `product-menu.tsx` tiles degrade gracefully to the product name on a brand-colour background until these exist.                                                                                                                           |

## Intentionally empty

| Path      | Why                                                                                                                                                                                                                                                                                                       |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fonts/`  | Variable fonts are **self-hosted via npm** (`@fontsource-variable/inter`, `@fontsource-variable/fraunces`), imported in `app/[locale]/layout.tsx`. EEA-compliant: no runtime third-party font CDN, no fabricated font binaries (F-fix). This directory is a placeholder for any future self-hosted faces. |
| `status/` | Placeholder for status-page assets. The live status page is `https://status.viavitae.com` (a contact channel in `lib/constants.ts`), not a local file.                                                                                                                                                    |

Empty directories are preserved with `.gitkeep`.
